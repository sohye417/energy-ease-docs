# So erhalten Sie KeyID und KeySecret

Um SolisCloud mit Energy Ease zu verbinden, benötigen Sie die KeyID und das KeySecret von SolisCloud.

Weitere Informationen finden Sie in der [offiziellen Solis-Dokumentation](https://doc.soliscloud.com/en/20.API%20documentation/01.SolisCloud%20Platform%20API%20Document.html).

Befolgen Sie die Schritte unter **"2. API to Obtain Single Account Permission"**, um Ihre KeyID und Ihr KeySecret zu erhalten.
