# Comment obtenir la KeyID et le KeySecret

Pour connecter SolisCloud à Energy Ease, vous devez obtenir la KeyID et le KeySecret depuis SolisCloud.

Pour plus d'informations, veuillez consulter la [documentation officielle de Solis](https://doc.soliscloud.com/en/20.API%20documentation/01.SolisCloud%20Platform%20API%20Document.html).

Suivez les étapes indiquées dans **"2. API to Obtain Single Account Permission"** pour obtenir votre KeyID et votre KeySecret.
